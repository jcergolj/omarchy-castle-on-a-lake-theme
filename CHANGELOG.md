# Changelog

All notable changes to this project are documented in this file.

## [1.2.0] - 2026-08-26

- Replaced Aether-generated palette with wallpaper-derived colors — every
  hue drawn from specific elements in the castle paintings (sandstone,
  firelight, sage, lake reflections, storm sky, twilight violet)
- Added custom Neovim colorscheme (`neovim.lua`) with full highlight groups
  for editor, syntax, Treesitter, LSP, and popular plugins
- Converted preview image from JPEG to PNG
- Expanded Theme Files listing in README with lock screen and license files

## [1.1.0] - 2026-08-16

- Rewritten README with the day/night background switching front and centre
- Added a desktop preview image
- Added GitHub release badge and changelog
- Clarified artwork licensing and attribution

## [1.0.0] - 2026-08-16

- Initial release of the Castle on a Lake theme for Omarchy Quattro
- Four castle wallpapers (two scenes, day and night versions)
- Automatic day/night background switching helper
- MIT-licensed theme code
